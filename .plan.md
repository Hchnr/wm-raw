## 架构说明

### 模型结构 (7.28B total)
```
WorldModel
├── vlm (VLMBranch, ~4B)              ← Qwen3-VL-4B-Instruct
│   ├── embed_tokens
│   ├── vision_encoder (24 blocks)
│   ├── layers (36 DecoderLayers)
│   ├── norm
│   └── lm_head
├── state_diffusion (StateDiffusionBranch, ~2B)  ← Qwen3-VL-2B-Instruct
│   ├── input_proj
│   ├── time_embedder + time_conditioner
│   ├── adaln_layers (28 AdaLN modules)
│   ├── layers (28 DiffusionDecoderLayer → .layer = DecoderLayer)
│   ├── position_embedding
│   ├── final_norm
│   └── output_head
└── cross_attention (CrossAttentionStack)         ← random init
    └── 28 CrossAttentionAdapter layers
```

### 权重加载策略
- VLM: 从 Qwen3-VL-4B-Instruct 加载全量 (embed + vision + decoder + norm + lm_head)
- Diffusion backbone: 从 Qwen3-VL-2B-Instruct 只加载 decoder layers + norm
- Diffusion 其他 (input_proj, output_head, adaln, timestep, position_embed): random init
- Cross attention: random init

### Optimizer 设计 (3 param groups)
| Group | LR | 包含 |
|-------|-----|------|
| adapter | 1e-4 | cross_attention, input_proj, output_head, adaln, time_embed, position_embed |
| diffusion | 1e-5 | state_diffusion.layers + final_norm |
| vlm | 1e-6 | vlm.* (可选，默认 frozen) |

### FSDP2 配置
- Per-layer sharding: 每个 DecoderLayer 独立 shard unit
- `reshard_after_forward=True` (root model: False)
- Mixed precision: compute=bf16, params=bf16
