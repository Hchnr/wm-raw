## Phase 1: Project scaffold + Config
1. `pyproject.toml` — minimal package definition
2. `src/wm_raw/__init__.py`
3. `src/wm_raw/config.py` — strongly-typed dataclasses for model/training config

## Phase 2: Core building blocks (`src/wm_raw/models/`)
4. `rope.py` — Static MRoPE (text) + RoPE (vision), no `.item()` calls
5. `qwen3vl_backbone.py` — RMSNorm, TextAttention (with QK-norm), TextMLP, DecoderLayer
6. `vision_encoder.py` — PatchEmbed, VisionBlock, PatchMerger, VisionModel (static shapes)
7. `embeddings.py` — ContinuousTokenProjector, LatentPositionEmbedding, patchify/unpatchify

## Phase 3: Model branches (`src/wm_raw/models/`)
8. `vlm.py` — VLMBranch: embed_tokens → vision_encoder → decoder layers → lm_head
9. `cross_attention.py` — CrossAttentionAdapter (cross_kv_down policy) + CrossAttentionStack
10. `adaln.py` — SinusoidalTimestepEmbedding, AdaLNZero
11. `diffusion_branch.py` — StateDiffusionBranch: tokenize → timestep_cond → layers+cross_attn → output_head
12. `model.py` — WorldModel: assemble VLM + Diffusion + CrossAttention + loss computation

## Phase 4: Utilities
13. `src/wm_raw/models/__init__.py` — public exports
14. `src/wm_raw/diffusion.py` — flow matching noise/loss (replaces edm.py for flow_matching objective)

## Implementation Notes

- Each file targets < 500 lines
- All tensor shapes annotated in comments
- No dynamic shape ops (nonzero, .item(), .tolist())  
- Weight names match HF checkpoint convention for easy loading
- Only `cross_kv_down` communication policy implemented
- Only state diffusion branch (no action, no trajectory context encoder)
- Flow matching objective (the default for GPIC config)
